# Gift of the Givers Foundation Website

## 1. Project Description

This project is a website developed for the Gift of the Givers Foundation. The purpose of the website is to provide information about the organisation, its humanitarian work, projects and ways in which members of the public can get involved.

The website is designed to be simple, user-friendly and easy to navigate.

## 2. Website Features

The website includes the following features:

- **Home Page:** Introduces the organisation and its work.
- **About Page:** Provides information about the organisation.
- **Our Work Page:** Explains the humanitarian activities of the foundation.
- **Projects Page:** Displays information about different projects.
- **Gallery Page:** Displays photographs of the organisation's activities, with a lightbox feature for viewing enlarged images.
- **Get Involved Page:** Provides information about supporting the organisation.
- **Contact Page:** Allows visitors to view contact information and complete a contact form.
- **Enquiry Page:** Allows visitors to submit enquiries.
- **Accordion:** Allows users to expand and collapse information on the About page.
- **Form Validation:** JavaScript checks that required form fields are completed.

## 3. Technologies Used

The following technologies were used to develop the website:

- **HTML5:** Used to create the structure and content of the webpages.
- **CSS3:** Used to style the website and create its layout.
- **JavaScript:** Used to add interactive features such as form validation, the accordion and image lightbox.

## 5. How to Run the Website

1. Download or extract the project folder.
2. Open the folder using Visual Studio Code.
3. Make sure all website images are saved inside the `images` folder.
4. Open `index.html` in a web browser.
5. Use the navigation menu to access the different website pages.

No additional software or database is required to view the basic website.

## 6. Testing

The website should be tested to make sure that:

- All navigation links open the correct pages.
- Images display correctly.
- The website layout works on different screen sizes.
- The accordion opens and closes correctly.
- Gallery images open in the lightbox.
- Contact and enquiry forms validate the required information.

## 7. Limitations

The contact and enquiry forms currently provide front-end validation and confirmation messages. They do not automatically send or store submitted enquiries because a backend service has not been connected.

## 8. Conclusion

The project demonstrates the use of HTML, CSS and JavaScript to develop a multi-page website for a humanitarian organisation. It aims to make information about the foundation accessible while allowing visitors to explore its activities and learn how they can offer support.
